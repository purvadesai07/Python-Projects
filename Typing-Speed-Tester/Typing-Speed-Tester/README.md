# Typing Speed Tester ⌨️

A simple Python project that tests typing speed and accuracy using randomly generated sentences.

## Features
- Random sentence generation
- Typing speed calculation
- Accuracy calculation
- Words Per Minute (WPM)

## Technologies Used
- Python
- time module
- random module

## How to Run

```bash
python typing_speed.py
```
